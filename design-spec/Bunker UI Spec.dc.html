Bunker: Who Stays
UI Spec / Unity uGUI + TextMeshPro / Portrait 1080×1920 @1x
The screen is a sealed room. Everything sits on unlit concrete; only the thing demanding a decision is lit.
One warm light source — amber — marks agency: whose turn it is, what you can still press. Deep red marks loss and expiry, and is never used for anything you can do.
Surfaces are flat plates with 1px machined borders and 2–8px radii. No gloss, no gradients except the hazard stripe and the vignette. Depth comes from a darker scrim and a hard offset shadow, not from blur stacks.
Type is stencilled and condensed for labels, humanist for values, monospaced for anything numeric or system-spoken. Labels are uppercase and letterspaced so Ukrainian strings stay legible when they run 2× long.
State is never colour alone: every state carries a glyph, a shape change, or a word. Eliminated players are stamped, not dimmed away.
Readability beats atmosphere at every conflict. Body text holds ≥4.5:1; the grain and vignette layers are non-interactive and clamp at 8% opacity.

Anchoring
Player bar — anchor top-stretch. Left/right inset 32, top inset 142 (110 status + 32). Height 112. Never scrolls.
Turn card — anchor top-stretch, inset 32, top 302. Height fits content; if content exceeds the gap to the reveal panel the card's slot list scrolls internally, the header stays pinned.
Reveal panel — anchor bottom-stretch, inset 0, bottom 0. Padding 32/32/56 (56 absorbs the home indicator). Height is driven by content; the button grid is a fixed 2×4 so the panel height is stable across states.
Vertical budget — 110 status + 32 + 112 bar + 48 gap + card + 24 gap + 560 panel + 56 inset. Card gets 878px at minimum; it is the only element allowed to flex.
Grain & vignette — two full-screen non-interactive Image layers at the very back of the canvas sort order, 5% and 8%. They tint, never carry meaning.
Reserved cell — the 8th grid cell stays empty and dashed at all times; the "Start discussion" button occupies it when the pass completes, so nothing reflows.

Expanded panel
Geometry — same x/width/top as the collapsed bar (32, 1016, 142). The bar becomes the panel's header; nothing jumps. Panel max height 1200; the row list is a scroll rect, header and footer pinned.
Rows — 120 tall (≥88 target), gap 12, padding 24. Two-line row: name at M/38 stencil, status line at XS/22 mono. Name is truncate-at-2-lines, not fixed width — Ukrainian names grow the row to 168 and the list keeps scrolling.
Tappable affordance — every row carries a › chevron at the right edge plus a 1px border; pressed state fills #2A2D2F and brightens the chevron. Eliminated rows stay tappable (you can still read a dead player's file) but their chevron is textDisabled.
Row states — current turn (amber plate + diamond + "REVEALING NOW"), you (white pip + YOU tag), alive, eliminated (hatched plate, strike-through in danger, EXPELLED stamp rotated −4°, round number), pressed, loading skeleton.
Close — 88×88 ✕ in the header, tap-outside on the scrim, and Android back. Scrim is a full-screen button, so tapping the game content behind never leaks through.
Empty — no such state in play: the list always holds the local player. A lobby with 1 player shows only your row plus "WAITING FOR SURVIVORS…" in the footer slot.

Geometry
Panel — anchor bottom-stretch, 1080 wide, height 560 fixed across all four states. Padding 32 / 32 / 56. Top edge is a 1px→2px line whose colour is the only structural state cue: border, danger, success.
Timer — 176 radial, 14px track, ring at (32,32). Numerals XL/96 mono, two digits always ("03" not "3") so the glyph box never reflows. Escalation: 15–11 accent, 10–6 warning, 5–0 danger + 2px ring, 1Hz two-step blink, panel glow, headline switches from "Your turn" to "Choose now".
Turn indicator — right of the ring, flexible width. Your turn: L/48 accent + solid caret. Waiting: M/38 textSecondary + hollow circle, name inline and allowed to wrap to 2 lines.
Grid — 4 columns × 2 rows, cell 238×112, gap 16. Labels are Saira Condensed 30 with auto-size floor 24 and 2-line wrap, so a 14-character Ukrainian label ("Особливість") fits without truncation. Cell 8 is permanently reserved.
Button states — four, all non-colour-coded
Enabled — #2B2318 plate, 2px accent border, accent label. The only outlined-in-amber element on screen.
Pressed — solid accent fill, black label, shadow removed, 80ms.
Already revealed — raised grey plate, label struck through, plus a green "✓ DONE" line. Locked reads as an outcome, not an absence.
Not your turn — sunken plate #191B1C, 1px border, textDisabled label, no ✓ line unless that trait is genuinely revealed. No border accent anywhere, so the panel is visibly not addressed to you.
Timeout — at 00 the client locks the grid, auto-reveals a random hidden trait, and the headline becomes "Time up — Baggage revealed" in danger for 1200ms before the turn passes.
05 · Z-order story
SORT 0 · BASE
Current-turn card
Always present. Amber top edge. No scrim, no back bar — there is nothing behind it.
SORT 10 · OVERLAY + SCRIM 72%
Browsed player card
Dashed frame + ‹ BACK bar naming what is underneath: "Back to Marta's turn".
SORT 20 · OVERLAY + SCRIM 72%
Expanded player list
Anchored to its own collapsed bar, so its origin is unambiguous. Opens above a browsed card and closes back to it.
SORT 30 · MODAL + SCRIM 88%
Special card modal
Only blocking layer. Heavier scrim, 3px accent frame, explicit Cancel / Confirm — no tap-outside.
Rules
One scrim per level. Each overlay owns its own scrim, so two stacked overlays read as two steps of darkness. The base card is never legible enough to be mistaken for interactive.
Frame vocabulary = depth. Solid accent top edge = base. Dashed grey = dismissible overlay. Solid 3px accent = blocking modal. You can name your layer without reading a word.
Every layer says where back goes. Overlays carry a ‹ bar naming the layer beneath; the modal carries a labelled Cancel. Android back and tap-outside pop exactly one level.
The reveal panel never moves. It stays at sort 0 under every scrim: your timer keeps running while you browse, and you can see it running.
Max depth 2 overlays + 1 modal. Opening a player card from the list closes the list rather than stacking a third panel.
